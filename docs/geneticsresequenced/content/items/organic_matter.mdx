**Organic Matter** contains information about an entity type. It can be acquired using the [Scraper](@genetics_resequenced:scraper).

It can be converted into [Cells](@genetics_resequenced:cell) in the [Cell Analyzer](@genetics_resequenced:cell_analyzer).
