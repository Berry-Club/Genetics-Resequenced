The **Speed** Gene gives entities the Speed potion effect.

## Obtaining

By default, you can get it from these sources:
- Dolphin: 2/11
- Fox: 2/9
- Horse: 3/16
- Ocelot: 2/10
- Rabbit: 3/17
- Skeleton Horse: 4/12
- Zombie Horse: 4/12
