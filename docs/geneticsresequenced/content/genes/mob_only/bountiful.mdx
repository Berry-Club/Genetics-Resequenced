The **Bountiful** Gene makes it so that when the mob that has it dies, its loot is treated as if they were killed with more Looting than they were.

For example, an unenchanted sword would be treated as if it had Looting I. A Looting V sword would be treated as if it had Looting VI.

The **Bountiful II** Gene does the same, but adds +2 Looting instead of +1.

## Obtaining

By default, level 1 can be obtained from these sources:
- Mooshroom: 2/13

And level 2 can be obtained from:
- Sniffer: 3/7
