<PrefabObtaining/>

The **Dna Extractor** is used to convert [Cells](@genetics_resequenced:cell) and [GMO Cells](@genetics_resequenced:gmo_cell) into [DNA Helices](@genetics_resequenced:dna_helix).

Regular Cells will be turned into Helices with unknown Genes, but still containing the entity type information.genetics_resequenced

GMO Cells already contain the Genes, so the resulting DNA Helix will have the Gene set already.
