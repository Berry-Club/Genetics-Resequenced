<PrefabObtaining/>

The **DNA Extractor** is used to convert [Cells](@geneticsresequenced:cell) and [GMO Cells](@geneticsresequenced:gmo_cell) into [DNA Helices](@geneticsresequenced:dna_helix).

Regular Cells will be turned into Helices with unknown Genes, but still containing the entity type information.

GMO Cells already contain the Genes, so the resulting DNA Helix will have the Gene set already.
