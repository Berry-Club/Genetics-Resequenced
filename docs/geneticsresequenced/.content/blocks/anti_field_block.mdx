The Anti-Field Block prevents certain Genes from working while nearby.

The default radius of effect is 25 blocks, but this can be changed in the server config.

It can disable the following Genes:
- [Item Magnet](@geneticsresequenced:genes/item_magnet)
- [XP Magnet](@geneticsresequenced:genes/xp_magnet)
