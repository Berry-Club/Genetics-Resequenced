The **Meaty** Gene allows entities to be sheared to spawn a Raw Porkchop. Players can sneak right-click Shears to shear themselves, if they have the Gene.

It can be mutated into **Meaty II**, which causes the entity to occasionally drop a Cooked Porkchop.

## Obtaining

By default, you can get it from these sources:
- Hoglin: 5/10
- Pig: 2/7
- Piglin Brute: 4/9
- Piglin: 3/8
- Zoglin: 4/9
- Zombified Piglin: 3/11
