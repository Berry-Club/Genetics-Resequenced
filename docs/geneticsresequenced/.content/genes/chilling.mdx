The **Chilling** Gene makes it so that when the entity makes a melee attack, the target has a chance of being [frozen](https://minecraft.wiki/w/Powder_Snow#Freezing) for a short duration.

By default there's a 75% chance of freezing the target for 15 seconds. These values can be changed in the mod config.

## Obtaining

By default, you can get it from these sources:
- Husk: 4/9
- Snow Golem: 2/7
