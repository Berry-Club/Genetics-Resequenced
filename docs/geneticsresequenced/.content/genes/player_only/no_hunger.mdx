The **No Hunger** Gene prevents a player's hunger bar from depleting below a certain amount. It does not provide saturation.

By default, every 4 seconds it increases the player's food level to a maximum of 10 points. Both of these values can be changed in the server config.

## Obtaining

By default, You can get it from these sources:
- Allay: 5/8
- Endermite: 2/6
