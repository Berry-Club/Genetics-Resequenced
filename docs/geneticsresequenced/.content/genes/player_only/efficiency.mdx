The **Efficiency** Gene increases the player's dig speed, mimicking the effect of the Haste status effect.

It also _stacks_ with the Haste effect, _and_ with the actual Efficiency enchantment!

## Obtaining

By default, You can get it from these sources:
- Allay: 5/8
- Endermite: 2/6
