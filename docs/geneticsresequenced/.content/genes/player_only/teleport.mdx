The **Teleport** Gene allows the player to teleport a short distance by using a specified keybind (unset by default).

By default, the player will teleport up to 10 blocks in the direction they're facing. This distance can be changed in the server config.

Players will **not** teleport through blocks. If the path is interrupted, the player will teleport there instead.

## Obtaining

By default, you can get it from these sources:
- Enderman: 3/9
- Phantom: 3/11
