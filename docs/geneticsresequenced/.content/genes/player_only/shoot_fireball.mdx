The **Dragon Breath** Gene allows the player to fire a small Fireball projectile by right-clicking a Blaze Rod.

More specifically, it's when you use an item with the `#geneticsresequenced:activates_shoot_fireball_gene` tag.

## Obtaining

By default, you can get it from these sources:
- Blaze: 3/12
- Ghast: 4/9
