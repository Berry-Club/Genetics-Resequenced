The **Mob Sight** Gene allows the player to see mobs through walls.

It has a default radius of 32 blocks, which can be changed in the server config.

## Obtaining

By Default, you can get it from these sources:
- Elder Guardian: 3/7
- Guardian: 3/12
- Warden: 5/10
- Bat: 3/8
