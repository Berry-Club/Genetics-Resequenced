The **Thorns** Gene gives entities a chance to reflect damage onto melee attackers. It only works if the entity's chestplate is either missing or Leather.

By default there's a 15% chance to inflict 1.5 points of damage (0.75 hearts) to the attacker when hit, using 1 point of hunger. These values can be changed in the server config.

## Obtaining

By default, you can get it from these sources:
- Bee: 3/8
- Pufferfish: 4/16
