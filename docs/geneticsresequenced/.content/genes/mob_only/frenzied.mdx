The **Frenzied** Gene makes it so the mob that has it will attack everything nearby.

If the mob normally cannot attack, it will deal 3 points (1.5 hearts) of damage.

## Obtaining

By default, level 1 can be obtained from these sources:
- Zoglin: 3/12
