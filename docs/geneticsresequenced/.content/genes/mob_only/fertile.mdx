The **Fertile** Gene makes it so that when the mob that has it breeds, it produces additional offspring.

Each parent that has the Gene adds an additional child. If both parents have it, they will produce a total of 3 children.

## Obtaining

By default, level 1 can be obtained from these sources:
- Rabbit: 3/20
