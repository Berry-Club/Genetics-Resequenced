# KubeJS Support

## Events

While the mod doesn't explicitly have KubeJS support, it's relatively simple to implement it yourself!

### [GeneChangeEvent](https://github.com/Berry-Club/Genetics-Resequenced/blob/NeoForge-1.21/src/main/kotlin/dev/aaronhowser/mods/geneticsresequenced/event/custom/GeneChangeEvent.kt)

There are two GeneChangeEvents: Pre and Post.

Pre is fired before an entity's Genes are changed, and can be cancelled. Post is fired after, and cannot be cancelled.

Both of them have the following properties:
- `entity` - The LivingEntity whose Genes are changing
- `geneHolder` - The Holder\<Gene> of the Gene that's being added or removed
- `geneId` - The ResourceKey\<Gene> of the Gene that's being added or removed
- `isAddition()` - A Boolean representing whether the Gene is being added (true) or removed (false)

```js
NativeEvents.onEvent("dev.aaronhowser.mods.geneticsresequenced.event.custom.GeneChangeEvent$Pre", (event) => {
	let entity = event.entity;
	if (entity.level.isClientSide()) return;

	if (!event.isAddition() && entity.name.getString() == "1aaron5" && event.geneId == "geneticsresequenced:cringe") {
		event.canceled = true;
	}
});
```
```js
NativeEvents.onEvent("dev.aaronhowser.mods.geneticsresequenced.event.custom.GeneChangeEvent$Post", event => {
	event.entity.tell("Your genes have changed!")
})
```

### [ModifyEntityGenesEvent](https://github.com/Berry-Club/Genetics-Resequenced/blob/NeoForge-1.21/src/main/kotlin/dev/aaronhowser/mods/geneticsresequenced/event/custom/ModifyEntityGenesEvent.kt)

This event is fired every time something checks what Genes an entity can have, such as when a [Gene Checker](@geneticsresequenced:gene_checker) is used, or when the [DNA Decryptor](@geneticsresequenced:dna_decryptor) reveals a Helix's Gene.

ModifyEntityGenesEvent has the following properties:
- entityType: The EntityType being modified
- geneWeights: A MutableMap\<ResourceKey\<Gene>, Double> representing the gene weights for the entity
	- In KubeJS this is represented as a JS object, which means you can't modify it easily

There are also some useful methods on the event:
- getTotalWeights(): Int - Returns the total weight of all Genes
- getEntityTypeString(): String - Returns the String id of the EntityType, to make comparing easier
- getWeight(gene): Int - Returns the weight of a specific Gene
- setWeight(gene, weight) - Sets the weight of a specific Gene
- remove(gene) - Removes a Gene from the entity's possible Genes

`getWeight`, `setWeight`, and `remove` can all accept either a ResourceKey\<Gene>, or a String representing the Gene id.

```js
NativeEvents.onEvent("dev.aaronhowser.mods.geneticsresequenced.event.custom.ModifyEntityGenesEvent", (event) => {
	if (event.entityTypeString == "minecraft:cow") {
		event.setWeight("geneticsresequenced:lay_egg", 999);
		event.remove("geneticsresequenced:milky");
	}
});
```

### [ModifyGeneRequirementsEvent](https://github.com/Berry-Club/Genetics-Resequenced/blob/NeoForge-1.21/src/main/kotlin/dev/aaronhowser/mods/geneticsresequenced/event/custom/ModifyGeneRequirementsEvent.kt)

This event is fired when the mod checks if an entity can have a specific Gene. This usually only happens when the entity's Genes change.

ModifyGeneRequirementsEvent has the following properties:
- `gene` - The ResourceKey\<Gene> being checked
- `requirements` - A MutableSet\<ResourceKey\<Gene>> representing the Genes required to have the checked Gene

```js
NativeEvents.onEvent("dev.aaronhowser.mods.geneticsresequenced.event.custom.ModifyGeneRequirementsEvent", (event) => {
	if (event.gene == "geneticsresequenced:cringe") {
		event.requirements.add("geneticsresequenced:cursed")
	}
})
```

## Adding, Removing, and Querying Genes

```js
const $GenesData = Java.loadClass('dev.aaronhowser.mods.geneticsresequenced.attachment.GenesData')

$GenesData.addGene(livingEntity, "geneticsresequenced:chatterbox")
$GenesData.removeGene(livingEntity, "geneticsresequenced:lay_egg")
let hasSlimyDeath = $GenesData.hasGene(livingEntity, "geneticsresequenced:slimy_death")
```

This uses reflection to load the [GenesData](https://github.com/Berry-Club/Genetics-Resequenced/blob/NeoForge-1.21/src/main/kotlin/dev/aaronhowser/mods/geneticsresequenced/attachment/GenesData.kt) class, allowing you to use its functions.

(In Kotlin, a function that looks like `fun Example.doSomething(int: Int)` is actually compiled to `doSomething(Example, Int)` in Java)
