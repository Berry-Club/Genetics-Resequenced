# Gene Tags

You cannot unregister a Gene, but you _can_ disable them using tags.

There are 4 built-in Gene tags:

- `#geneticsresequenced:disabled`
	- Stops the Gene from functioning
	- Prevents it from the list of possible Genes
- `#geneticsresequenced:hidden`
	- Removes it from the Plasmid list
	- Currently only `geneticsresequenced:basic` has this, as it's not really a Gene
- `#geneticsresequenced:negative`
	- Marks the Gene as negative
	- Colors the Gene red
	- Prevents it from being given to Players (unless the server config is changed) (ignored by the Cringe gene)
- `#geneticsresequenced:mutation`
	- Colors the name purple

You can add these tags using KubeJS like so:

```js
ServerEvents.tags('geneticsresequenced:gene', event => {
  // Disables the Keep Inventory Gene, in case of conflicts with grave style mods etc
  event.add('geneticsresequenced:disabled', 'geneticsresequenced:keep_inventory')
})
```
