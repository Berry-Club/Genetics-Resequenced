# New Attributes

The mod uses a couple new Attributes to do various things. They're modified by Genes, but you can also modify them in other ways.

## Efficiency

Players have `genetics_resequenced:efficiency`, which increases the speed they mine at. It basically mimics the enchantment without actually requiring it.

It's used by the [Efficiency](@genetics_resequenced:efficiency) Gene.

## Base Looting

Mobs have `genetics_resequenced:base_looting`, which increases the loot they get from mobs. Basically, if they have the attribute at value 2.0, its drop calculation will think it was killed with Looting III if it was killed with Looting I, etc.

It's used by the [Bountiful](@genetics_resequenced:bountiful) Gene.

## XP Drop Multiplier

Mobs have `genetics_resequenced:xp_drop_multiplier`, which multiplies the amount of XP they drop. For example, if the mob has a value of 1.5, it will drop 50% more XP.

It's used by the [Experienced](@genetics_resequenced:experienced) Gene.
